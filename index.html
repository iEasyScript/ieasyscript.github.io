Questions

FAQ

What do I need to run these?

It varies by script — each one lists the client it runs on before you buy, and the setup guide walks you through it. Most need an up-to-date Java runtime.

Is there a subscription?

No. Every script is a one-off payment and the licence never expires. No monthly billing, nothing to cancel.

Do updates cost extra?

No. Bug fixes and new features for a script you own are included for as long as I maintain it.

Can I run it on more than one account?

A licence covers one account. Message me in Discord if you need multiple — there's a rate for that.

What if a script breaks after a game update?

Report it in the Discord bug channel. Breaking changes get patched first, ahead of anything else on the roadmap.

Is there a refund policy?

If a script doesn't work as described and can't be fixed within 72 hours, you get your money back. Bans aren't covered — see the note at the bottom of this page.
